# Сложно сосредоточиться

Адаптивная страница по макету Figma с тёмной, светлой и автоматической цветовой схемой.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Структура

- `index.html` — семантическая разметка страницы.
- `styles/` — глобальные стили, базовая тема, переменные и переопределения тем.
- `fonts/` — шрифт IBM Plex Mono.
- `images/` — фоновые изображения, галерея и фавиконки.
- `scripts/script.js` — переключение тем и сохранение выбора.

Тема «Авто» ориентируется на `prefers-color-scheme`; выбор пользователя сохраняется в `localStorage`.
